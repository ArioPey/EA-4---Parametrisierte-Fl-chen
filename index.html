Dokumentation

1. Möbius-Band

Eine einseitige Fläche mit einer halben Verdrehung. Sie wird aus einem Parameter u für den Kreis und v für die Breite erzeugt.

x = (1 + v·cos(u/2))·cos(u)
y = (1 + v·cos(u/2))·sin(u)
z = v·sin(u/2)

Parameterbereiche: u ∈ [0, 2π], v ∈ [-0.45, 0.45].

Quelle: 3D-Meier – Parametrisierte Flächen

2. Torus

Ein Torus entsteht durch zwei periodische Winkel. Die Fläche wird algorithmisch als regelmäßiges Parameter-Gitter erzeugt.

x = (R + r·cos(v))·cos(u)
y = (R + r·cos(v))·sin(u)
z = r·sin(v)

Mit R = 0.62, r = 0.25, u,v ∈ [0, 2π].

Quelle: 3D-Meier – Parametrisierte Flächen

3. Eigene Kreation: Wellenblüte ★

Diese Fläche ist eine eigene Kombination aus radialer Welle und einer zusätzlichen dreifachen Winkelmodulation. Dadurch entsteht eine blütenartige Oberfläche mit sechs sichtbaren Ausbuchtungen.

ρ(u) = 0.62 + 0.14·sin(3u)
x = ρ(u)·cos(u)·(0.78 + 0.22·cos(v))
y = ρ(u)·sin(u)·(0.78 + 0.22·cos(v))
z = 0.22·sin(v) + 0.08·sin(3u)

Parameterbereiche: u,v ∈ [0, 2π]. Die Formel wurde für diese Aufgabe selbst entwickelt.

Benutzung

  • B oder „Fläche wechseln“ schaltet zwischen den drei Flächen um.
  • „Modus“ wechselt zwischen Füllung + Linien, nur Füllung und nur Linien.
  • Alle Vertices werden algorithmisch aus den Parametern erzeugt.
  • Die Flächen werden in NDC skaliert, damit sie im Bereich −1 bis +1 bleiben.

Technische Umsetzung

Für jede Fläche wird ein regelmäßiges Parameter-Gitter erzeugt. Aus jeweils vier benachbarten Gitterpunkten werden zwei Dreiecke gebildet. Die Farbe wird abhängig von der Höhe und der Position des jeweiligen Vertex erzeugt. Dadurch entstehen flächenabhängige Farbverläufe. Zusätzlich wird ein separater Linien-Draw-Call über dieselben Indizes verwendet.

Fehlerbehandlung / QA

WebGL-Kontext, Shader-Kompilierung, Program-Linking und Draw-Fehler werden geprüft. Öffne in Chrome die Entwicklertools und kontrolliere die Console.
